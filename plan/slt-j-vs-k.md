# Column J against column K, target by target

The planner now carries two written sets: **J Student Learning Target** and **K New SLTs**. Neither is the generated set live on Andamio. Each pair below is judged on the same four tests: an observable verb, a single checkable claim, fidelity to what the lesson actually teaches, and whether the module's assignment evidences it.

Column letters are as the file stands on Drive at 22:54 on 30 July. The General filename column has been removed, so everything shifted one to the left.

## Three things to settle regardless of which column wins

1. **Row 17.** J calls Review a fifth stage of the Edify 4D Journey. The deck teaches four: Discover, Define, Design, Deploy. Either the deck is out of date or the target is.
2. **Row 20.** J calls it the Real Value Growth Engine, K the Full Value Growth Engine. The deck uses both. Pick one name and use it everywhere.
3. **Row 33.** 306.1 Value Types still has no deck and no lesson, so any target for it is written ahead of the content rather than from it.
